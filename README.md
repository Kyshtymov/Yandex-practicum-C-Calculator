# 🧮 Qt Calculator

Интерактивный калькулятор с графическим интерфейсом на **Qt**, реализованный в рамках финального задания спринта. Проект сочетает объектно-ориентированную архитектуру, работу с пользовательским вводом и строгий подход к стилю кода.

---

## 📋 Описание

Калькулятор предоставляет графический интерфейс для выполнения базовых арифметических операций и поддерживает расширенный набор функций: возведение в степень, работу с памятью и редактирование ввода. Логика вычислений вынесена в отдельный класс `Calculator`, а взаимодействие с пользователем реализовано через Qt-виджеты в классе `MainWindow`.

---

## ✨ Возможности

- ➕ Базовые арифметические операции: сложение, вычитание, умножение, деление
- ⬆️ Возведение в степень
- 🔢 Поддержка чисел с плавающей точкой через псевдоним `Number`
- 💾 Работа с ячейкой памяти: `MS` (сохранить), `MR` (загрузить), `MC` (очистить)
- 🔄 Инверсия знака числа (`reverse`)
- ⌫ Удаление последнего введённого символа (`delete`)
- 🧹 Очистка текущего ввода и формулы (`clear`)
- 🖥️ Интерактивный графический интерфейс на Qt
- 🧱 Разделение логики и представления (класс `Calculator` + `MainWindow`)
- 📐 Соблюдение строгого стиля кода

## 🧠 Архитектура

### Класс `Calculator`

Отвечает исключительно за математическую логику. Не зависит от GUI, что позволяет легко тестировать его отдельно.

### Псевдоним `Number`

Для удобства смены типа вычислений введён псевдоним:

```cpp
using Number = double;
```

Если потребуется перейти на `float`, `long double` или даже пользовательский тип — достаточно изменить **одну строку**.
